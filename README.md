# econ_energy_markets_public_lighting
This repository contains the scripts to replicate the results presented in the report from Grégoire Glorieux, Louison Guegaden, Cyril Vial, and Nadia Zargouni. 

The script `get_panel.ipynb` merges all the data sources into a single panel dataset at the level of the municipality x year. 
The script `eclairage_ore_cerema.ipynb` follows with the rest of the analysis and creates the main figures and tables in a `figures/` subfolder.
